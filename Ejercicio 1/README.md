## Ejercicio 1
## Parte A:
1) ¿Cuáles son las reglas escritas del lenguaje?
  Algunas de las reglas son:
 -Variables: let, const, var. Permiten almacenar datos y valores.
 -Operadores:+,-,*,/,==,!=,===,!==,<,>,<=,=>,||,&&. operaciones matemáticas,logicas y comparaciones 
 -Estructuras de control:if,elseif,else,switch,for,while,do while,for. Determinan el flujo del programa
 -Funciones: Conjunto de instrucciones que permiten realizar tareas y  reutilizar codigo
 -Bloques de codigo:{} organizar el codigo en bloques.
 
2) ¿Qué características particulares del lenguaje se
cree que sean "mejores" que en otros lenguajes?
  Algunas caracteristicas son:
  a- Simplicidad: sintaxis sencilla
  b- Flexibilidad: utiliza diferentes formas de programar y trabajar con distintos tipos de datos
  c- Compatibilidad: funciona en la mayoria de los navegadores y sistemas

## Parte B:

1) ¿Tiene una sintaxis y una semántica bien definida? ¿Existe documentación oficial?
      -Si,JS posee una sintaxis y una semantica bien definidas.Se establece como se declaran variables y funciones,se utilizan los operadores y funcionan las estructuras de control como if, for y while
       -Existe documentación oficial y estándares como ECMAScript, que establecen las características y el comportamiento del lenguaje

2) ¿Es posible comprobar el código producido en ese lenguaje?
 Si,se detectan errores de sintaxis antes o durante la ejecucion y muestran informacion para que puedan ser corregidos. Ademas, el código puede probarse mediante herramientas de depuracion y pruebas para verificar que el programa funcione como se espera.

3) ¿Es confiable?
  Es confiable si es utilizado correctamente, ya que permite detectar y manejar determinados errores durante la ejecución mediante mecanismos como try...catch. Aunque algunos errores pueden no ser detectados hasta que el programa se ejecuta

4) ¿Es ortogonal?
  Posee un cierto grado de ortogonalidad, ya que muchas de sus características pueden combinarse entre sí(Ejemplo: Las estructuras de control pueden utilizarse junto con variables, operadores y funciones.),pero existen casos particulares en los que determinadas características tienen comportamientos especiales o no pueden combinarse libremente

5) ¿Cuáles son sus características de consistencia y uniformidad?
 Las características de consistencia y uniformidad son:

-Las instrucciones generalmente terminan con ;
-Las estructuras de control utilizan una sintaxis comun
-Las funciones siguen una forma determinada para recibir parametros y devolver valores
-Los operadores mantienen una forma similar de utilización en diferentes expresiones

6) ¿Es extensible? ¿Hay subconjuntos de ese lenguaje?
 Es extensible porque permite agregar funcionalidades mediante librerias, APIs y diferentes herramientas.Posee subconjuntos, que consisten en utilizar solamente una parte de las caracteristicas del lenguaje

7) El código producido, ¿es transportable?
 Es transportable debido a que existen diferentes implementaciones del lenguaje y estandares comunes como ECMAScript. Un programa en JS puede ejecutarse en diferentes sistemas y dispositivos que dispongan de un entorno compatible especialmente en navegadores web sin necesidad de reescribir completamente el codigo, pero si se utilizan caracteristicas especificas de un determinado entorno o navegador puede ser necesario realizar modificaciones para ejecutarlo en otro entorno.
